The board's detail view now renders task descriptions and Task Updates as GitHub Flavored Markdown, so a task reads the same on the board as on GitHub. Strikethrough, tables, task lists, footnotes, and bare URLs all render.

Wide tables scroll sideways inside the detail pane. Task-list checkboxes are read-only. A bare URL opens in a new tab, the same as any other external link.
